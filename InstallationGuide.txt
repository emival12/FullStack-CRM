# ISTRUZIONI CREAZIONE BACKEND (DEV):
## 1: Installare MySql Server e configurare l'utenza

## 2: Creare la cartella di backend
mkdir backend

## 3: Installare le estensioni
cd backend

## 3.0: Estensione pytest (serve a gestire i test in python) 
pip install pytest              => pytest (per lanciare i test) o pytest --cov=. --cov-report=html (per lanciare i test con la coverage mostrata graficamente)

## 3.1: Estensione FastApi (serve a gestire le chiamate al middleware) 
pip install fastapi 

## 3.2: Estensione uvicorn (serve a lanciare il server) 
pip install uvicorn 

## 3.3: Estensione mysql-connector-python (serve a parlare con mySQL) 
pip install mysql-connector-python

## 3.4: Estensione python-multipart (serve a passare file compressi, serve per pasare l'excel) 
pip install python-multipart

## 3.5: Estensione per la gestione delle formule
pip install simpleeval

## 3.6: Estensione bcrypt (serve a criptare la password) 
pip install bcrypt

## 4: Dentro il file main.py
        Modificare i parametri affinche combacino con l'utente configurato in ## 1

##: Comando per lanciare il Server Backend in sviluppo
uvicorn main:app --reload




# ISTRUZIONI CREAZIONE FRONTEND (DEV):
## 1: Creare il sito React (installa automaticamente delle estensioni)
npx create-react-app frontend

## 2: Installare le estensioni
cd frontend

## 2.1: Istallazione libreria React dom v18 in locale 
        (Anche se ## 1 installa già react abbiamo bisogno di questa versione in particolare, 
        perchè il router non gestisce ancora l'ultima versione)
npm install react@18 react-dom@18

## 2.2: Istallazione libreria React router v7.0.4 in locale (Libreria React per la gestione della navigazione tra pagine)
npm install react-router-dom@7.9.4

## 2.3: Istallazione libreria React bootstrap in locale (Libreria con una serie di componenti grafici utili)
npm install react-bootstrap bootstrap

## 2.4: Istallazione libreria React Hook Form in locale (Libreria per la gestione dei form)
npm install react-hook-form

## 2.5: Istallazione libreria bootstrap icon in locale (Libreria con icone)
npm install bootstrap-icons

## 2.6: Istallazione libreria bootstrap per le textarea
npm install react-textarea-autosize

## 2.7: Istallazione libreria axios in locale (Libreria React per fare richiest HTTP e comunicazione con API)
npm install axios

## 2.8: Istallazione libreria per i test puri
npm install -D vitest    => npm test (per lanciare i test)

## 2.9: Istallazione libreria per i test di hook
npm install -D jsdom @testing-library/react @testing-library/dom

##: Comando per lanciare il Server Fronted in sviluppo
npm start

REORDER_FIELD temporary solution:
SELECT * FROM record_layout_definition WHERE object_name = 'tipologia_documento' AND record_type_name = 'master' ORDER BY sort_order;

UPDATE record_layout_definition 
SET sort_order = CASE field_name
    WHEN 'id'                           THEN 1 
    WHEN 'descrizione'                  THEN 2 
    WHEN 'descrizione_tipo_documento'   THEN 3
    WHEN 'create_date'                  THEN 4
    WHEN 'last_modified_date'           THEN 5
    WHEN 'last_modified_by'             THEN 6
END
WHERE object_name = 'tipologia_documento' AND record_type_name = 'master';
